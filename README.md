# Sistema de Cadastro de Alunos

Projeto desenvolvido em linguagem C com o objetivo de praticar conceitos fundamentais de programação, como estruturas, vetores, laços de repetição, condições e manipulação de dados.

## Funcionalidades

- **Cadastrar aluno:** registra ID, nome, idade e nota.
- **Listar alunos:** exibe os dados de todos os alunos cadastrados.
- **Buscar aluno:** localiza um aluno pelo ID.
- **Calcular média:** calcula a média das notas dos alunos cadastrados.
- **Encerrar sistema:** finaliza a execução do programa.

## Tecnologias utilizadas

- Linguagem C
- Biblioteca padrão `stdio.h`


## Conceitos praticados

- `struct` para organizar os dados dos alunos.
- Vetores para armazenar múltiplos registros.
- `if` e `switch` para controle de fluxo.
- Laços `for` e `do-while`.
- Entrada e saída de dados com `scanf`, `fgets` e `printf`.
- Acumulação de valores e cálculo de média.

## Objetivo

Consolidar os fundamentos da linguagem C por meio da construção de um sistema de cadastro com funcionalidades interativas via terminal.
